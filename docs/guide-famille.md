# Guide de la famille : l'appli de l'oliveraie d'Afourer

Cette appli permet de voir, depuis le téléphone, comment va l'oliveraie : l'argent dépensé, l'huile vendue, les récoltes et la pluie. On ne peut rien modifier : on regarde seulement.

## Installer l'appli sur Android

1. Ouvrir **Chrome** sur le téléphone.
2. Taper l'adresse de l'appli (Mhend vous l'envoie).
3. Appuyer sur les **trois points** en haut à droite.
4. Appuyer sur **Installer l'application** (ou **Ajouter à l'écran d'accueil**).
5. Appuyer sur **Installer**.

Une icône avec un rameau d'olivier apparaît sur l'écran du téléphone. Appuyez dessus pour ouvrir l'appli.

## Installer l'appli sur iPhone

1. Ouvrir **Safari** (pas un autre navigateur).
2. Taper l'adresse de l'appli.
3. Appuyer sur le bouton **Partager** (le carré avec une flèche vers le haut, en bas de l'écran).
4. Descendre et appuyer sur **Sur l'écran d'accueil**.
5. Appuyer sur **Ajouter**.

## Entrer le code

1. Ouvrir l'appli.
2. Un clavier avec des chiffres apparaît.
3. Taper les **5 chiffres** du code de la famille (Mhend vous le donne).
4. L'appli s'ouvre toute seule.

Si le code est faux, un message le dit : recommencez. Après 5 erreurs, il faut attendre 15 minutes. Une fois le code entré, l'appli vous reconnaît pendant plusieurs mois.

## Se déplacer dans l'appli

En bas de l'écran, 5 boutons :

- **Accueil** : le résumé de l'année.
- **Dépenses** : ce qui a été payé.
- **Ventes** : l'huile vendue et ce qu'il reste à encaisser.
- **Récoltes** : les kilos d'olives et les litres d'huile, année après année.
- **Météo** : la pluie et la prévision.

En haut, les **flèches** à côté de l'année permettent de regarder une autre année.

## Partager le résumé

Sur l'Accueil, tout en bas, appuyez sur **Partager le récap de l'année** : l'appli fabrique une image que vous pouvez envoyer par WhatsApp.

## Sans internet

Si vous n'avez plus de réseau, l'appli montre les dernières pages que vous aviez ouvertes, avec la date de la dernière mise à jour. Les chiffres se remettent à jour dès que le réseau revient.

## Un souci ?

Fermez l'appli et rouvrez-la. Si le problème continue, demandez à Mhend.
